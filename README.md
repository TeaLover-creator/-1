1. Что повышается
Linux: одна команда (sudo команда).
Windows: весь процесс/приложение целиком.

2. Кто спрашивает пароль
Linux: свой пароль пользователя (если он в sudoers).
Windows: пароль администратора, либо просто «Да» для админа.

3. Гранулярность
Linux: тонкая - можно разрешить конкретные команды в /etc/sudoers.
Windows: почти бинарно - либо обычный токен, либо elevated.

4. Время действия
Linux: на команду или короткий кэш (5–15 мин).
Windows: пока открыт процесс.

5. Модель прав
Linux: временно получаешь права root.
Windows: получаешь полный токен администратора.

6. Учётная запись
Linux: обычно одна учётка + sudo.
Windows: отдельный тип учётки "администратор" + UAC.

7. Аналог
sudo «выполнить эту команду от админа».
Режим админа в Windows ≈ "запустить это приложение от админа".
